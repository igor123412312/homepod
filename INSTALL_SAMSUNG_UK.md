# Як зібрати й встановити HomePod Music v0.6 на Samsung Galaxy Fold

**Важливо:** файл, який надається, — ZIP **вихідного коду**, а не готовий APK. Спочатку треба зібрати APK через GitHub Actions. Не встановлюй `prepare.py` або ZIP як Android-додаток.

## Частина A: підготовка на комп'ютері (найпростіше через GitHub Desktop)

1. Завантаж архів `HomePodMusic-v0.6-Source.zip` із чату та розпакуй його на Windows.
2. Перевір, що серед файлів є `prepare.py`, `README_UK.md` і прихована папка `.github/workflows/build-apk.yml`. У Windows Explorer увімкни **View → Show → Hidden items**.
3. Відкрий https://github.com/new під своїм GitHub-акаунтом. Назва: `homepod-music`, доступ — **Private**; натисни **Create repository**. У власному репозиторії не повинно бути чужого коду.
4. Встанови GitHub Desktop з https://desktop.github.com/ (якщо його немає); відкрий **File → Clone repository → URL**, введи URL твого нового репозиторію, вибери локальну папку.
5. Скопіюй **весь вміст** розпакованого ZIP до локальної папки репозиторію, включно з `.github` (але без зайвої зовнішньої папки архіву).
6. У GitHub Desktop перевір список файлів, уведи короткий коміт `HomePod Music v0.6`, натисни **Commit to main**, потім **Push origin**.
7. Відкрий власний репозиторій на сайті GitHub → **Actions** → `Test and build HomePod Music v0.6`. Якщо GitHub просить увімкнути Actions, погоджуйся тільки для свого приватного репозиторію.
8. Збірка запуститься після push. Також можна натиснути **Run workflow** → **Run workflow**. Відкрий останній run, перевір кроки. **Зелений статус означає, що збірка/автоматичні тести пройшли; не означає, що HomePod фізично перевірено.**
9. Внизу сторінки успішного run в **Artifacts** натисни `HomePod-Music-v0.6-debug-APK`. Скачається ZIP. Розпакуй його, всередині буде `app-debug.apk`. Якщо run червоний, **не встановлюй APK** — прочитай помилку у кроці Gradle або Emulator.

## Частина B: передати APK на Samsung

1. З'єднай Samsung із комп'ютером USB-кабелем; на телефоні вибери **File transfer** (передавання файлів), якщо з'явиться запит. Або скористайся Quick Share.
2. Скопіюй **`app-debug.apk`**, а не вихідний ZIP, до папки `Download` / `Завантаження` Samsung.
3. На Samsung відкрий **Мої файли (My Files)** → **Завантаження** → `app-debug.apk`.
4. Якщо Android запитає, чи дозволити встановлення з цього джерела, перевір, що це саме APK із твого власного успішного GitHub Actions. Дозволь інсталяцію **лише для цього джерела**, якщо правила безпеки телефона дозволяють, і заверши встановлення. Після встановлення можна знову вимкнути дозвіл.
5. Якщо система безпеки або керування телефоном забороняє встановлення, **не обходь захист**; використовуй штатні засоби розробника/Android Studio або політику власника пристрою.
6. Якщо Android повідомляє `App not installed` після попередньої debug-версії, причина може бути в іншому ключі підпису. За потреби видали старий debug-додаток (це видалить його налаштування) і встанови новий.

## Частина C: перший запуск і підключення до HomePod mini

1. Телефон і HomePod mini підключи до **однієї домашньої Wi-Fi мережі**, не до гостьової з ізоляцією пристроїв. HomePod має бути попередньо налаштований через Apple Home на пристрої Apple.
2. Відкрий застосунок **HomePod Music**.
3. Надійшли запити на дозволи? Дозволь запис аудіо для **захоплення системного відтворення** (мікрофон не використовується для трансляції) і потрібні мережеві дозволи. Сповіщення — необов'язкові, але корисні для видимості тривалого сеансу.
4. Дочекайся списку колонок. Якщо HomePod не відображається, натисни **Оновити пошук колонок** і перевір Wi-Fi/VPN/ізоляцію мережі.
5. Натисни назву свого **HomePod mini** у списку (або **Підключити й відкрити YouTube Music**, якщо колонка вже збережена).
6. Android покаже системний діалог **захоплення екрана/аудіо**. Підтвердь його: застосунок записує лише аудіо YouTube Music, а не відео екрана; попередження системи загальне для MediaProjection.
7. Якщо HomePod запитає код або підтвердження, натисни **Додаткове керування та PIN** і завершуй pairing через штатний інтерфейс.
8. Коли HomePod перейде у статус відтворення, автоматично відкриється **YouTube Music**. Увімкни трек; перевір, що звук іде саме з HomePod. Можлива помітна затримка на старті.
9. Для зупинки повернись у HomePod Music і натисни **Зупинити трансляцію**; або використовуй кнопку у шторці.

## Частина D: додати кнопку в шторку Samsung

1. Проведи вниз від верхньої частини екрана, за потреби ще раз — відкрий **Quick Settings / Швидкі налаштування**.
2. Натисни **олівець / Edit / Редагувати** або меню налаштування кнопок (точна назва залежить від One UI).
3. У списку доступних кнопок знайди **HomePod Music**, перетягни її до активних і натисни **Готово**.
4. Натиснення при вимкненій трансляції відкриє швидке підключення до збереженого HomePod і, за потреби, системний діалог Android. Повторне натиснення під час трансляції зупинить її.
5. Якщо плитки немає, перезапусти телефон після інсталяції та перевір список знову.

## Частина E: робота у фоні та типові проблеми

- Якщо музика зупиняється при блокуванні екрана: **Налаштування Samsung → Акумулятор → Обмеження фонового використання → Програми, що ніколи не переходять у сон** → додай `HomePod Music`. Назви пунктів можуть трохи відрізнятися. Це може збільшити витрату батареї.
- Якщо HomePod не знайдено: Wi-Fi той самий? Вимкнена ізоляція клієнтів і гостьова мережа? VPN не блокує локальну мережу? Спробуй Refresh.
- Якщо HomePod підключено, але звук тихий: гучність у нашому застосунку, самого HomePod і YouTube Music. Перевір, чи YouTube Music дозволяє захоплення звуку на цій версії.
- Якщо відмовив у MediaProjection: запусти підключення ще раз; дозвіл потрібен для **нового** сеансу.
- Якщо відмовив у сповіщеннях: це не повинно блокувати трансляцію (виправлено в v0.6).
- Якщо Android Update або HomePod firmware змінив поведінку: подивись `QA_REPORT.md`, перевір статус нових релізів centuryplay; автоматично новий код у наш фіксований v0.6 не підтягується.

## Важливі попередження

- У YouTube Music на Android натискання його власної кнопки **Cast** не показуватиме HomePod як Google Cast пристрій. Трансляція працює через HomePod Music.
- Застосунок **не** тестувався тут на фізичному Samsung/HomePod; якщо GitHub Actions не проходить, потрібні логи для виправлення. Це не підтверджений реліз для широкого розповсюдження.
