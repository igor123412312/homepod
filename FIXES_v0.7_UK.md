# HomePod Music v0.7.0 — аудит і виправлення

## Підтверджені результати v0.6.1

- 14 листопада APK та JVM-тести зібралися успішно.
- GitHub Actions отримав Failure на етапі Android-емулятора: три Espresso-тести завершилися `RootViewWithoutFocusException`. Це може бути спричинено системним діалогом або станом емулятора; це **не** доказ падіння застосунку.
- Під час запуску звичайного інтерфейсу застосунок сам ініціював запит системних дозволів. Новий потік дозволів запускається лише через явну кнопку користувача.
- Для Android 17 і `targetSdk 35` попередня логіка помилково вимагала `ACCESS_LOCAL_NETWORK` за фактом версії OS. Документація Android вказує, що при `targetSdk <=36` локальна мережа тимчасово доступна через `INTERNET`, тому цей запит забрано.
- В маніфесті також прибрано `NotificationListenerService` (ще в v0.6.1) і вимкнено cloud backup pairing credentials.

## Реалізовано в v0.7.0

1. Чітка кнопка «Надати дозволи та знайти HomePod» при першому запуску.
2. Пошук HomePod запускається лише після перевірки дозволів Android.
3. Балансування startDiscovery/stopDiscovery під час переходу в YouTube Music.
4. Прибрано зайвий мережевий дозвіл для цільового SDK 35.
5. Збережено MediaProjection, AirPlay 2, ручне підключення, Quick Settings, збережені колонки.
6. Новий CI-контроль упакованого AndroidManifest на зайві дозволи.

## Які ще ризики залишаються

- Play Protect може блокувати sideload навіть після видалення NotificationListener, тому не вимикайте захист. Потрібен новий скріншот після встановлення v0.7.0.
- AudioPlaybackCapture не може записати звук, заборонений політикою джерела. Це залежить від версії YouTube Music.
- Кнопка Cast у YouTube Music і системний Output Switcher — різні інтерфейси. Показ HomePod у Cast не гарантований.
- Тільки реальний тест Samsung Galaxy Fold + HomePod підтвердить AirPlay 2, гучність, аудіо й фонову роботу.
- Якщо після оновлення виникає «Пакет не встановлено», можлива різниця ключів підпису debug APK між GitHub Actions run: потрібно видалити попередню тестову версію (це очистить її дані).

## Порядок перевірки

1. GitHub Actions -> збірка v0.7.0 -> зелений статус та APK-артефакт.
2. Встановлення: не вимикайте Play Protect, не використовуйте сторонні APK.
3. Головний екран: перед натисканням не повинен автоматично вимагати дозволів.
4. Натисніть кнопку дозволів і погодьтеся з RECORD_AUDIO / Nearby devices за потреби.
5. Увімкніть Wi-Fi; виберіть HomePod mini в списку.
6. «Підключити й відкрити YouTube Music» -> MediaProjection -> YouTube Music -> музика.
7. Перевірте stop/reconnect, блокування екрана, плитку Quick Settings, вибір гучності.
8. Якщо проблема лишилась, надішліть точний скріншот і крок, на якому вона виникає.
