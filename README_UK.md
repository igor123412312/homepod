# HomePod Music v0.6 — персональний Android-застосунок

**Призначення:** Samsung → YouTube Music → HomePod mini через AirPlay 2 у домашній Wi-Fi мережі. Без власного сервера та AirMusic.

Цей архів містить **відтворюваний вихідний код/патчі**, а не APK. Додаток спирається на `g8row/centuryplay` v2.1.2 (`e241344a61008936186718ee0b2feec40ab81e79`, ліцензія AGPL-3.0). Усі зміни виконуються лише після завантаження цього точного коміту.

## Можливості

- Перша активація: вибери HomePod зі списку, підтверди системний дозвіл MediaProjection, після успішного з'єднання YouTube Music відкриється автоматично.
- Подальше підключення: обирається лише **збережений** HomePod. При недоступності у Wi-Fi випадкова інша колонка не підміняє його.
- Плитка HomePod Music в Android Quick Settings (натисни, щоб підключити або зупинити сеанс).
- Зупинити трансляцію прямо з головного екрана.
- Гучність обраної колонки 0–100%, збереження значення між запусками.
- Ручне оновлення списку колонок, кнопка відкриття YouTube Music, доступ до розширеного екрана для PIN.
- Аудіозахоплення **лише** UID YouTube Music. Не захоплює інші медіапрограми, сповіщення чи дзвінки. Android може заборонити захоплення аудіо окремого застосунку; наш код цього не обходить.
- Повноекранний запит дозволу Android для нової MediaProjection-сесії. Утримання вже активного сеансу дозволяє обійти *повторний* запит під час цього ж сеансу, але не у новій сесії.
- Відхилення **необов'язкового** дозволу сповіщень більше не блокує підключення. Дозвіл на захоплення аудіо, як і раніше, потрібний.
- Інтерфейс зі ScrollView і обмеженням ширини для зовнішнього та внутрішнього екранів Galaxy Fold.

## Обмеження

- Кнопка Google Cast **всередині** YouTube Music не показує HomePod автоматично. Це інший протокол. Системний Android Output Switcher, який підтримує centuryplay, не рівнозначний внутрішньому меню Google Cast.
- Можлива затримка звуку близько 1–3 секунд, особливо при першому підключенні; реальна затримка залежить від мережі та HomePod.
- Підтримка HomePod mini в centuryplay — не офіційна інтеграція Apple; після зміни прошивки можливі збої.
- Якщо HomePod очікує підтвердження або PIN, відкривається розширене керування. Не кожен такий сценарій можна автоматизувати.
- Android і YouTube Music можуть змінювати політику аудіозахоплення; роботу потрібно перевірити на твоєму телефоні.

## Як отримати APK

Використай `INSTALL_SAMSUNG_UK.md`. Рекомендований спосіб — **GitHub Actions** у власному репозиторії. Workflow:
1. Перевіряє Python-патчі.
2. Завантажує конкретний Git-коміт centuryplay; відхиляє неправильну версію.
3. Збирає Android APK та інструментовані Android-тести, запускає JVM unit-тести.
4. Перевіряє APK як ZIP і завантажує його в Artifacts.
5. Запускає 3 UI smoke-тести на Android 15 емуляторі (API 35). Вони не тестують фізичний HomePod.

При встановленні іншої debug-збірки з іншим підписом може знадобитися видалити попередню версію; тоді обрану колонку потрібно зберегти заново.

## Локальна перевірка

```bash
python3 -m unittest discover -s tests -v
kotlinc overlay/QuickConnectPolicy.kt tests/PolicyChecks.kt -include-runtime -d /tmp/policy.jar
java -jar /tmp/policy.jar
bash build-linux.sh
```

В останньому кроці потрібні інтернет, Git, Android SDK/NDK/CMake та Java 17. На Windows використовуй `build-windows.ps1` у PowerShell із установленими Android Studio, Git і Python 3.
